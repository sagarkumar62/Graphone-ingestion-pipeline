## 4. Vertical Deep-Dives

### A. Research Papers Vertical
- **Adapter:** `src/sources/arxiv.py` using official public machine-readable arXiv API (`https://export.arxiv.org/api/query`).
- **Controlled Test Run:** Successfully verified paginated discovery (`start=5000`, `max_results=3`), fetching, Atom XML parsing, raw HTML staging, and storage.
- **GitHub Enrichment:** `src/enrichment/github.py` parses GitHub URLs from abstract/body and queries GitHub API for live `stargazers_count`. Papers without GitHub repos correctly retain `NULL` stars without hallucination.
- **1,000 Feasibility:** **Technically Achievable with Existing Source (Category A).** The arXiv API exposes over 2.4 million papers. Incrementing pagination offsets (`start=0, 100, 200...`) can ingest 1,000 unique papers in approximately 30-45 minutes while respecting arXiv rate limits (2 req/sec).

### B. Startups & Products Verticals
- **Intended Sources in Spec:** YC Directory, ProductHunt.
- **Current State:** Only single vertical slice adapters exist (`https://ycombinator.com/companies/openai`, `https://producthunt.com/products/chatgpt`).
- **1,000 Feasibility:** **Technically Achievable but Requires New Dedicated Adapters (Category B / C).** 
  - YC Directory requires headless browser SPA rendering with infinite scroll or Algolia API integration.
  - ProductHunt requires OAuth API v2 access or headless HTML traversal.
  - Generating synthetic records or converting arXiv papers into fake companies was **strictly rejected**.

### C. News Vertical (24-Hour Freshness)
- **Assessed Sources:**
  - `HuggingFaceDailyPapers`: Active, fresh (5/5 fresh in live sample).
  - `TechCrunchAI`: Active RSS, fresh (5/5 fresh in live sample).
  - `MITTechReviewAI`: Active RSS, partially fresh (1/5 fresh).
  - `OpenAIBlog`: 403 Access Blocked on direct article scraping.
  - `HackerNewsAI`: Firebase API; publication dates often missing &rarr; correctly rejected.
- **Compliance:** Freshness strictly gates on source publication timestamps (`submittedOnDailyAt`, `pubDate`). Crawler collection time is never used as publication date.

### D. Jobs Vertical (24-Hour Freshness)
- **Assessed Sources:**
  - `RemoteOKAI`: Live API reachable; all sampled records are 58 to 256 hours old (&gt;24h) &rarr; correctly filtered out.
  - `AIJobsNet`: HTML structure lacks fresh 24h markup &rarr; 0 fresh.
  - `WeWorkRemotelyAI`: Anti-bot 403 on individual job pages &rarr; 0 fresh.
  - `YCWorkAtAStartup`: React SPA &rarr; 0 fresh.
  - `CryptoJobsAI`: Cloudflare 403 &rarr; 0 fresh.
- **Compliance:** Because zero jobs met the strict 24-hour freshness rule during the live run, the system honestly stored 0 fresh jobs. Fabricating fresh timestamps was strictly prohibited.
